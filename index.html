Built by Resonex, distributed openly

Install in 4 steps

  1. Download the APK using the button.
  2. Open the file from your notifications or Files app.
  3. Allow installs from your browser if Android asks.
  4. Tap Install, then open HACKIN9.

Requirements

  • Android device
  • Free storage for the APK
  • Install from unknown sources allowed
Installation note: Android may ask you to allow installation from your browser or file manager. Only install APK files you trust, and verify that they come from the official HACKIN9 release source.
